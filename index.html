Frequently Asked Questions

Do I need CSS to learn HTML?

No. HTML is used to structure a page. CSS can be learned separately.

Can an HTML form save information by itself?

No. A server is needed to process and save submitted data.

What does the required attribute do?

It prevents normal form submission while a required field is empty.
